# SERARA CHARACTER IDENTITY PASS 01
Date: 2026-09-21
Status: ACTIVE

## Goal

Move from "generic rigged human" toward a recognizably SERARA silhouette while preserving the working skeleton, posture engine and web runtime.

This pass is intentionally structural before decorative.

## Identity direction

SERARA should feel:
- humanoid immediately
- elongated rather than athletic
- sculptural rather than game-avatar-like
- pale / mineral / porcelain
- graceful in neutral state
- slightly uncanny before any Fall effect appears
- readable at phone scale
- neither obviously angelic nor demonic by costume

## Pass 01 changes

### Silhouette
- narrower overall width
- longer-feeling limbs
- thinner forearms / lower legs
- longer neck
- slightly elongated head
- reduced head width
- slightly narrower torso / pelvis

### Surface
- lighter porcelain/mineral base
- lower metallic response
- tighter roughness
- restrained warm internal emissive tint

### Motion
- deterministic bind-pose based posture engine
- no cumulative quaternion drift
- procedural breath integrated into spine/neck
- Grace / Tension / Fall remains on the same skeleton

## Important boundary

This is NOT the final sculpt.

The current CC0 low-poly mesh is still a development carrier for:
- silhouette decisions
- bone proportions
- posture language
- material behavior
- camera framing

The final custom SERARA mesh will replace it once these decisions are stable.

## Next identity passes

### Pass 02 — FACE / MASK
Target:
- remove generic low-poly facial read
- create a smooth SERARA face/mask layer
- narrow eye region
- stronger cheek/jaw planes
- longer cranium / neck continuity
- minimal mouth
- avoid human-realistic uncanny valley

### Pass 03 — HANDS / SHOULDERS
Target:
- more expressive hand silhouette
- longer fingers where rig allows
- cleaner shoulder-to-neck line
- Grace posture should read from silhouette alone

### Pass 04 — CANONICAL SCULPT
Target:
- custom authored mesh
- topology appropriate for deformation
- preserved compatible rig or retargeted canonical skeleton
- facial morph/blendshape strategy
