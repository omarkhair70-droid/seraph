# SERARA // THE WAKING RELIC — Experience Direction

Status: ACTIVE EXPERIENCE PROTOTYPE

This branch turns the accidental monolithic reconstruction into an intentional interactive entity.

## Identity
SERARA is not presented as a conventional character. She is a dormant relic: feminine, monolithic, half-awake, listening before speaking.

## Core states
1. Dormant
2. Sensing
3. Watching
4. Awakening
5. Calling
6. Fading

## Interaction grammar
- pointer proximity / hover -> sensing
- sustained hover -> watching
- click/tap -> awakening jolt
- scroll -> chamber transition
- inactivity -> fading

## Motion language
Keep motion scarce. The body should feel heavy and ancient.
- micro sway
- minute head/neck drift
- subtle vertical resonance
- activation tremor
- internal seam pulse

Avoid human gesturing, large turns, dance-like movement, or expressive facial acting.

## Sound language
- low evolving drone
- distant mineral/glass resonance
- sparse sub pulses
- feminine intimate whisper
- long reverb tails
- no conventional beat

## Voice lines used by prototype
- You woke what was sleeping.
- Stay close.
- There is a shape inside your silence.
- Now it opens.
- Follow the seam.
- I will remain.

## Visual language
- near-black chamber
- pale mineral / porcelain body
- warm internal seam
- cold rim light
- low fog and bloom-like halo
- text kept secondary to presence

## Technical intent
The first slice is a standalone Next.js / React Three Fiber hero experience using the current relic mesh as a deliberate visual direction. Model material, motion, sound, and voice are authored at runtime so the source mesh stays replaceable.
