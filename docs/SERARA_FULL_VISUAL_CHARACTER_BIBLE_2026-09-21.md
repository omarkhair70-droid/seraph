# SERARA — FULL VISUAL + CHARACTER BIBLE
Date: 2026-09-21
Status: CANONICAL / ACTIVE UNTIL VISUAL CLOSURE

## Canonical rule

SERARA does not use v1 / v2 / pass-01 / pass-02 naming for core creative direction.

There is one canonical FULL document for the visual and character identity.
It is edited in place while the work is active.
It becomes CLOSED only when the actual rendered character and world match the document strongly enough on real devices.

Historical experiments may exist in git history, but they are not promoted as parallel "versions" of the identity.

---

# 1. WHAT SERARA IS

SERARA is an embodied relic: a living sculptural presence that sits between body, artifact, atmosphere and signal.

It must not read as:
- a stock humanoid
- a game avatar
- a conventional angel
- a conventional demon
- a mannequin
- a shader demo
- a fashion character with effects pasted on top

It should read as:
- a being
- a ritual object
- a body that carries material history
- a surface capable of remembering touch / motion / stress
- something that could exist as sculpture even if the browser disappeared

Primary experience:
`SERARA://01 — FALL / ASCENT`

---

# 2. CORE VISUAL THESIS

The visual idea is not "angel becomes demon."

The real axis is:

COHERENCE
-> STRAIN
-> FRACTURE
-> FALL
-> AFTERMATH
-> RE-FORMATION

Grace and Fall are expressed through:
- anatomy
- silhouette
- posture
- material
- internal light
- sound
- temporal memory

The same being remains present throughout.

No model swap.

# 3. REFERENCE SYSTEM

SERARA does not copy any one reference.

The reference field combines separate lessons:

## Spatial / interactive precedent — Hollow / immersive WebGL
Use:
- limited palette
- spatial darkness
- unusual navigation / gesture-led interaction
- the feeling of entering a place rather than viewing a page

Do not copy:
- literal visual motifs
- environmental storytelling structure

## Body as energy conductor — Iris van Herpen
Use:
- body / atmosphere boundary
- material behaving as stored energy
- gesture triggering visible energy events
- sculptural silhouette
- engineered materiality

Do not copy:
- garment forms
- runway styling
- couture decoration

## Conceal / reveal identity — Nick Cave Soundsuits
Use:
- figure can become presence rather than portrait
- surface can obscure ordinary human identity
- silhouette and material can carry the character
- movement can make material audible / legible

Do not copy:
- ceremonial costume motifs
- found-object surface language

## Artifact / erosion logic — Daniel Arsham
Use:
- surface can imply history
- erosion / fracture should reveal another material condition
- patina and damage should feel structural, not decal-based

Do not copy:
- crystal erosion signature
- archaeology styling literally

## Execution standard — Active Theory / FWA-scale immersive work
Use:
- technical performance is part of art direction
- interaction, rendering, sound and environment are one system
- mobile/browser constraints are designed around, not ignored

## Synthetic self / adaptive body — Universal Everything, Future You
Use:
- the body can activate a synthetic being rather than merely control it
- movement can alter form while the digital being preserves its own identity
- generated variation should make encounters non-identical
- collapse / transformation can be part of the encounter lifecycle

Do not copy:
- robotic visual language
- mirror-one-to-one movement as the final SERARA behavior

## Gaze as character — Random International, Audience / Alone Together
Use:
- very small orientation changes can imply attention and personality
- a system can notice a visitor without becoming a puppet
- gaze may lag, hesitate, select or avoid full confrontation
- attention itself is an event

Do not copy:
- surveillance framing
- literal mirror mechanics

## Breath beyond the body — Marshmallow Laser Feast, Works of Nature / Evolver
Use:
- breath can connect body, atmosphere and world state
- internal systems can become landscape
- audiovisual rhythm can make invisible life-processes perceptible

Do not copy:
- anatomical visualization literally
- meditation language as interface copy

# 4. THE BODY

SERARA must remain immediately humanoid.

The body is not anatomically ordinary.

## Proportion target

- tall, elongated presence
- narrow pelvis
- narrow torso
- shoulders present but not heroic
- long neck
- forearms slightly long
- lower legs slightly long
- hands slightly enlarged / elongated
- fingers visually important
- head slightly narrower and vertically longer than a normal realistic head

The deformation should stay plausible enough that the viewer reads "body" before "monster."

## Gender read

Avoid strongly coded masculine bodybuilding or strongly coded feminine hourglass anatomy.

The presence should remain intentionally unresolved.

## Body rule

Even with:
- no shader
- no sound
- no camera input
- no particles

the silhouette must already feel like SERARA.

---

# 5. HEAD / FACE

The face is not a realistic human portrait.

It is closer to a smooth sculptural mask grown from the same material as the body.

## Target

- elongated cranium
- restrained jaw
- narrow eye region
- minimal mouth
- subtle nose ridge
- readable brow / cheek structure
- no generic videogame face
- no cartoon skull
- no literal horror makeup

## Eyes

The eyes should read as depth / signal, not cosmetic eyeballs.

Grace:
- dark recess
- warm internal point or thin reflected light

Tension:
- asymmetry
- internal light becomes less stable

Fall:
- recess deepens
- light breaks / shifts / disappears in one region
- face remains composed enough to avoid horror cliché

## Mouth

A line / seam / subtle opening.

It is not a talking-character mouth by default.

---

# 6. HANDS

Hands matter because they are where:
- gesture
- intention
- openness
- defense
- contact

become legible.

Target:
- long fingers
- narrow palms
- graceful neutral hanging pose
- tension visible through curl / spread
- no mitten-like low-poly read
- no exaggerated monster claws

Later hand tracking should map to the character without turning SERARA into a mirror puppet.

---

# 7. POSTURE LANGUAGE

## GRACE

Read:
- vertical
- open
- quiet
- structurally coherent

Body:
- chest open
- shoulders released
- neck long
- chin controlled
- pelvis balanced
- knees unlocked but stable
- arms hang with intentional softness

Motion:
- slow breath
- micro sway
- slight delayed response
- no idle-game loop feel

## TENSION

Read:
- contradiction entering the body

Body:
- one shoulder rises / rotates differently
- spine develops asymmetry
- neck and ribcage disagree
- weight begins to drift
- hands gain tension

Motion:
- breath shortens
- small tremor / delay
- response is less symmetrical

## FALL

Read:
- coherence is failing, not "evil mode"

Body:
- head gains weight
- upper spine compresses
- pelvis shifts
- knees compensate
- limbs hang with delayed recovery
- silhouette becomes less vertically organized

Motion:
- internal lag
- incomplete recovery
- local jerks may appear rarely
- never becomes ragdoll comedy

## RE-FORMATION

Read:
- a new equilibrium, not reset

Some scars, asymmetry or material memory remain.

# 8. MATERIAL SYSTEM

The body is one material system with state.

Base family:
- porcelain
- pale mineral
- bone-like ceramic
- restrained translucent subsurface feeling

Avoid:
- glossy plastic
- normal skin shader
- chrome
- cyberpunk emissive overload

## GRACE MATERIAL

- pale warm mineral
- very soft internal amber
- smooth macro surface
- subtle fine grain
- low visual noise

## TENSION MATERIAL

- warmer sub-surface activity
- stress lines
- veins of internal light
- directional surface strain
- controlled roughness change

## FALL MATERIAL

- dark mineral intrusion
- ash / wine / oxidized warmth
- cracks as structural stress paths
- internal ember visible through select fractures
- erosion / thinning in limited regions
- asymmetry

## Material law

Damage is never a PNG crack texture pasted over the body.

It must come from:
- shader fields
- geometry deformation
- masks derived from local stress/state
- procedural temporal memory

---

# 9. LIGHT

The chamber does not "light the model."

Light is part of the being.

## Chamber lighting

- mostly black / near-black
- soft warm key
- low warm-red lateral fill
- controlled head / sternum readability
- floor barely present
- no showroom lighting

## Internal light

Grace:
- sternum / head / select veins

Tension:
- unstable distribution

Fall:
- hotter, narrower, deeper
- visible through fractures
- not globally brighter

# 10. COLOR

Primary field:
- near-black
- chalk / porcelain
- warm bone
- muted clay
- restrained amber
- wine / deep mineral red
- ash

No rainbow state language.
No neon cyan / magenta cyberpunk fallback.

Color must correspond to material state.

# 11. CHAMBER

The first chamber should feel:
- undefined in scale
- quiet
- ritual
- not a room asset
- not a game level

Elements:
- darkness
- floor only where grounding requires it
- haze / depth
- very limited geometry
- light falloff creates architecture without walls

SERARA remains the spatial anchor.

---

# 12. CAMERA / COMPOSITION

Desktop:
- whole-body composition should be possible
- enough negative space around the figure
- character should not sit dead-center at all times once the encounter evolves

Mobile:
- face / torso readability cannot be sacrificed
- camera can move between full body and closer encounter states
- no accidental clipping

The camera participates in the encounter but never behaves like a game orbit viewer by default.

---

# 13. MOTION

Motion should feel authored even when procedural.

Principles:
- slow before fast
- delayed before mirrored
- asymmetric before random
- stillness is an event
- micro-motion is more important than constant spectacle

Avoid:
- looping idle animation visible as a loop
- perpetual floating
- generic breathing scale animation
- exaggerated physics

---

# 14. SOUND

Sound is part of the body.

Base vocabulary:
- breath-like air
- low harmonic drone
- ceramic friction
- body resonance
- distant metallic/mineral resonance
- internal electrical / plasma-like instability only when justified

Grace:
- stable harmonic relation
- open air

Tension:
- detuning
- filtering
- interrupted breath rhythm

Fall:
- low resonance
- fractured harmonics
- spatial instability
- selective silence

Sound must react to:
- posture
- distance
- body state
- movement
- later: user body input

---

# 15. USER BODY RELATIONSHIP

SERARA should not become a puppet controlled one-to-one.

The user's body is interpreted.

Signals:
- openness
- ascent
- shoulder asymmetry
- proximity
- stillness
- movement energy
- held pose
- hand state later

Examples:
- openness can release chest / light
- ascent can restore vertical coherence
- violent repeated motion can increase strain
- stillness can allow re-formation
- proximity can change attention / sound / head response

The world has memory and resistance.

---

# 16. INTERACTION

Primary interaction should feel discovered rather than explained.

Avoid:
- HUD meters
- tutorial arrows
- game buttons
- visible skeleton tracking
- constant text prompts

System permission prompts are unavoidable boundaries.

After permission, the body / device / space should become the interface.

---

# 17. TRANSFORMATION SYSTEM

Transformation must be continuous.

State is multidimensional:
- grace
- tension
- fall
- memory
- calm
- proximity
- user semantic pose

No binary angel/demon switch.

The same frame may contain:
- graceful posture
- lingering scar
- internal tension

This contradiction is desirable.

# 19. CANONICAL ASSET REQUIREMENTS

The final SERARA sculpt must have:
- authored topology
- clean deformation around neck / shoulders / elbows / knees
- proper hand topology
- face topology able to support subtle deformation
- skeleton compatibility / retarget plan
