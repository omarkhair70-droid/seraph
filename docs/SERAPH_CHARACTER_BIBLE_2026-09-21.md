# SERAPH CHARACTER BIBLE
Date: 2026-09-21
Character: SERAPH-01
Status: PRE-MODEL LOCK

## Presence

SERAPH-01 is recognizably humanoid but not an ordinary realistic person.

Target:
- slender / elongated proportion
- readable head, neck, ribcage, pelvis, shoulders, arms, hands, legs
- readable face planes
- restrained and uncanny, not monstrous by default
- sculptural rather than game-avatar cosmetic

The viewer should immediately understand:
"there is a being here."

## Face

The face matters.

It needs:
- readable eye sockets / eye line
- brow plane
- nose bridge
- mouth/jaw silhouette
- enough topology or morph support for subtle expression later

We do not need photoreal skin.

We do need a face that can become:
- serene
- alert
- strained
- fractured
- withdrawn
without swapping to another mesh.

## Rig

Minimum skeleton support:
- root / hips
- spine chain
- neck / head
- clavicles
- upper/lower arms
- hands
- upper/lower legs
- feet

Preferred:
- fingers
- facial blend shapes or a face rig
- jaw
- eyes

## Motion language

DORMANT:
- almost still
- low breathing
- micro head drift

GRACE:
- chest open
- shoulders released
- neck long
- upward vector
- slow controlled movement

TENSION:
- asymmetric shoulders
- breath interruption
- subtle hand tension
- neck / ribcage disagreement

FALL:
- compression
- off-axis spine
- head weight
- joint sharpness
- delayed recovery
- body remains alive, never becomes a ragdoll unless intentionally designed

## Transformation law

The character remains the same being.

Transformation happens through:
- pose
- rig state
- blend shapes
- shader material
- procedural deformation
- light
- audio
- temporal memory

No "swap angel model for demon model."
