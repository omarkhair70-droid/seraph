# SERAPH WORLD BIBLE
Date: 2026-09-21

## World

SERAPH is not a conventional fantasy universe with exposition first.

The world is discovered through matter, sound, posture and consequence.

The first environment should feel like an impossible chamber:
- no obvious walls
- depth emerges from fog / light / shadow
- scale is ambiguous
- the character feels physically present
- the viewer's own body changes the chamber indirectly

## Meaning of Grace

Grace is not "good points."

Grace is:
- coherence
- openness
- vertical lift
- harmonic stability
- breathable space
- luminous internal structure

## Meaning of Fall

Fall is not "evil mode."

Fall is:
- accumulated instability
- asymmetry
- compression
- fracture
- detuning
- material memory
- loss of structural coherence

## Re-formation

Recovery is never a reset button.

After the fall:
- some scars remain
- some sound relationships remain altered
- the body can find a new stable configuration
- the new state can be beautiful without returning to the original form

## Visual language

Grace:
- porcelain / pearl / pale mineral
- internal warm light
- soft gold
- subtle translucency
- long vertical silhouette
- smooth tension

Conflict:
- warm coral veins
- directional stress
- shadow gathering in joints / face planes
- unstable highlights

Fall:
- wine / obsidian / ash
- cracks
- sharpened silhouette
- compressed posture
- internal ember
- broken symmetry

Avoid:
- literal halos as default iconography
- cartoon wings
- horns
- generic hellfire
- cyberpunk neon
- game HUD meters in the final experience
