# SERAPH PHASE INDEX
Date: 2026-09-21
Status: ACTIVE

## Phase 00 — Foundation
Repo, architecture, CI, source-of-truth docs, runtime shell.

## Phase 01 — THE BODY
Canonical humanoid asset, rig, facial readability, idle life, camera framing, performance baseline.

## Phase 02 — MATERIAL NERVOUS SYSTEM
Grace / tension / fall shader system, scars, internal light, procedural deformation, material memory.

## Phase 03 — EMBODIED PERCEPTION
Pose semantics, hands when justified, proximity, held gestures, temporal intent, graceful fallback.

## Phase 04 — TRANSFORMATION ENGINE
State machine, hysteresis, long-form progression, irreversible/partially reversible consequences.

## Phase 05 — SOUND BODY
Procedural audio, spatial layers, harmonic stability/instability, breath, impact, silence as state.

## Phase 06 — ENCOUNTER
A complete single-person experience with beginning, escalation, consequence and ending/re-entry.

## Phase 07 — TWO PRESENCES
Realtime shared world: another person's body changes the same system.

## Phase 08 — MEMORY
Persistent traces across sessions / visitors.

## Phase 09 — PHYSICAL OBJECT
NFC / physical token / sensor bridge into SERAPH.

## Phase 10 — SPACE
Projection / room-scale installation / tracked bodies.

## Phase 11 — XR
AR/VR spatial version where hardware support makes sense.

## Completion rule

A phase is not complete because code exists.

It closes only after:
- build and lint pass
- real-device behavior is observed
- the intended experiential change is perceptible
- regressions are documented
